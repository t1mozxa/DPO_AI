# Итоговый проект по курсу «Инженерия Искусственного Интеллекта»

Проект Predict Used Car Price — это ML-пайплайн для прогнозирования цен подержанных автомобилей. Проект демонстрирует применение методов машинного обучения: работу с данными, предобработку, обучение модели, развёртывание REST API-сервиса и тестирование.

---

## 1. Паспорт проекта

- **Название проекта:** Predict Used Car Price — Прогнозирование цен подержанных автомобилей
- **Автор:** Малыгин Тимофей Алекссевич
- **Группа:** ЭФБО-05-22
- **Контакт:** @timozxa

- **Краткое описание (2-4 предложения):**  
  Проект посвящён построению сервиса прогнозирования цен подержанных автомобилей на основе датасета ~1M записей. Используются методы машинного обучения (Random Forest Regressor) для предсказания цены автомобиля на основе его характеристик. Результат — REST API сервис с эндпоинтами для прогноза, метрик и важности признаков.

---

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `notebooks/` – экспериментальные ноутбуки:
  - `eda.ipynb` – EDA, отдельные эксперименты.
- `src/` – основной код проекта:
  - `data.py` – модуль для работы с данными (загрузка и обработка);
  - `train.py` – обучение модели;
  - `service.py` – FastAPI сервис для API.
- `configs/` – конфигурационные файлы:
  - `settings.yaml` – настройки проекта (путь к данным, параметры модели).
- `tests/` – тесты.

## 3. Требования и установка

### 3.1. Требования

- Python `>= 3.11`
- Установленные системные зависимости: `pip`

### 3.2. Установка окружения

```bash
# Перейти в папку проекта
cd DPO_AI/project

# Создать виртуальное окружение (опционально, но рекомендуется)
python -m venv .venv

# Активировать окружение:
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# Установить зависимости
pip install --upgrade pip
pip install -r requirements.txt
```

## 4. Как запустить проект

### 4.1. Запуск обучения модели

```bash
cd DPO_AI/project
python -m src.train
```


### 4.2. Запуск сервиса (API/веб-интерфейс)

```bash
cd DPO_AI/project
python -m src.service
```

Сервис поднимается на порту **8000**.

**Доступные эндпоинты:**
- `GET /` – информация о сервисе и список эндпоинтов
- `POST /predict` – прогноз цены автомобиля
- `GET /health` – проверка сервиса
- `GET /metrics` – метрики качества модели
- `GET /features` – важность признаков

**Тестирование работоспособности:**
- Открыть http://localhost:8000 в браузере
- Swagger UI: http://localhost:8000/docs
- Пример curl запроса:
  ```bash
    curl -X 'POST' \
  'http://127.0.0.1:8000/predict' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "Brand": "string",
  ```

## 5. Данные

- **Источник:** Открытый датасет цен подержанных автомобилей Индии (~1M записей).
- **Данные:** Для обучения используется открытый датасет used_car_price_prediction_1M.csv (вариант c 10000 строк). В репозитории лежит только небольшая подвыборка в data/used_car_price_prediction_10k.csv. Полную версию датасета при необходимости можно скачать по инструкции из data/README.md.
- **Признаки:** Brand, Year, Kms_Driven, Fuel_Type, Transmission, Owner_Count, Mileage, Engine, Power, Seats, Name, New_Price, City, Seller_Type.

## 8. Ограничения и дальнейшая работа

В текущей версии:
- Используется базовая модель Random Forest без тонкой настройки гиперпараметров.
- Нет логирования запросов и хранения истории прогнозов.
- Данные загружаются из CSV файла при каждом запуске.

В дальнейшем можно добавить:
- Docker-контейнеризацию для развёртывания;
- Базу данных для хранения истории прогнозов;
